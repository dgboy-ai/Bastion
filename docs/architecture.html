⚙️ Bastion Engine & Logic Controllers
CORE CONTROLLER
🧠 Memory Tiers
• Session Memory: Ephemeral contexts with auto-promotion.
• Long-Term (LTM): Gateway layer avoiding duplicate LLM reads if similarity threshold is ≥80%.
🔎 Retrieval System
Fuses 4 distinct signals: 40% Vector Embeddings + 30% BM25 Keyword MATCH + 15% Entity Hops + 15% Time-Decay weights.
🌳 Knowledge Graph
Performs natural language entity and relationship extraction. Uses CockroachDB Recursive CTEs for BFS multi-hop graph hops.
🔄 Conflict Resolution
Conflict-Free Replicated Data Types (CRDT) with VectorClocks. Employs SELECT FOR UPDATE locks to prevent concurrent write skew.
🛡️ OWASP ASI06 Guard
Defends against memory poisoning. Automatically filters homoglyphs, visual confusables, and normalized leetspeak injection.
😴 Sleep-Time Consolidation
Background daemon consolidates duplicate events, ranks importances, prunes noise, and promotes episodic entries to semantic rules.
🔁 Saga Rollbacks
Crash-safe transaction tracking. Employs automatic compensating transactions to reverse memory writes if agent tasks fail.
💰 Spend Manager
Monitors limits for storage, search, embedding, and healing. Automatically suspends agents if daily cost limits are exceeded.
