Every arrow is a real call path. The dashed loop is the part no vector store can run.

External Services
HuggingFace Inference API Tier 1

BAAI/bge-large-en-v1.5 — 1024-dim embeddings via HTTP API. Falls back to local MiniLM on 503 or missing HF_TOKEN.

Local SentenceTransformer Tier 2

all-MiniLM-L6-v2 — 384-dim (padded to 1024). Pre-warmed in background thread to eliminate 28s cold start. Zero network cost.

Hash Fallback Tier 3

Character n-gram (2/3/4-gram) feature hashing into 1024-dim vector. Deterministic, no model required. Air-gapped environments.

Groq API Optional

LLM semantic classification for the OWASP ASI06 guard. Model: openai/gpt-oss-120b. Detects nuanced prompt injection when BASTION_LLM_GUARD=true.

AWS KMS Production

ECDSA-P256 asymmetric signing — private key never leaves KMS. Also provides envelope encryption for memory_store_encrypted. Dev mode uses local HMAC-SHA256.

AWS S3 CDC Archive

CockroachDB CDC changefeed output lands in cdc-live/ prefix. S3CdcTailer polls for event-driven hash-chain verification.

CockroachDB — The Memory
agent_memory Core Table
CREATE TABLE agent_memory ( memory_id UUID PRIMARY KEY DEFAULT gen_random_uuid(), agent_id STRING NOT NULL, memory_type STRING NOT NULL, -- fact, episodic, semantic, task, session... content TEXT NOT NULL, embedding VECTOR(1024) NOT NULL, metadata JSONB, previous_hash STRING, -- chain link to prior memory cryptographic_hash STRING NOT NULL, -- HMAC-SHA256(content, meta, prev) created_at TIMESTAMPTZ DEFAULT now(), expires_at TIMESTAMPTZ, -- native TTL auto-expiry importance_score FLOAT DEFAULT 5.0, trust_level FLOAT DEFAULT 2.0, is_pinned BOOL DEFAULT FALSE, -- survives context compaction pin_priority INT DEFAULT 0 ); CREATE VECTOR INDEX idx_memory_embedding ON agent_memory (agent_id, embedding); -- C-SPANN distributed index
agent_audit Append-Only Ledger
CREATE TABLE agent_audit ( audit_id UUID PRIMARY KEY, agent_id STRING NOT NULL, workflow_id UUID NOT NULL, action STRING NOT NULL, -- memory_store, memory_delete, heal... details JSONB, recorded_at TIMESTAMPTZ DEFAULT now() );
agent_entities / agent_relations Knowledge Graph

NLP-extracted entities and relations. BFS graph traversal via graph_query(). Temporal validity (valid_from/valid_until). Relations reference source memory for provenance.

agent_coordination Distributed Locks

Shared/exclusive lock types for resolve_conflict(). SERIALIZABLE isolation guarantees no split-brain. Expiry-based auto-release prevents deadlocks.

a2a_tasks / tool_usage_log Operational

A2A task state machine (SUBMITTED→WORKING→COMPLETED). Tool call logging with 30-day TTL. Budget tracking per agent.

The Write Pipeline — memory_store()
1
Guard Check

OWASP ASI06 scan: Unicode normalize → injection patterns → obfuscation decode → encoded payload scan → PII detect → optional LLM classify. Block before write.

2
Embed

Content → 1024-dim vector. 3-tier fallback: HuggingFace API → local MiniLM → hash feature hashing. L2-normalized.

3
Chain Lock

Acquire per-agent threading.Lock. Serializes same-agent concurrent writers in-process. Cross-agent safety via DB.

4
Hash Chain

HMAC-SHA256(content, metadata, prev_hash) with length-prefix encoding. KMS ECDSA-P256 in production.

5
SERIALIZABLE Insert

INSERT INTO agent_memory + INSERT INTO agent_audit in single transaction. Auto-retry on serialization failure (code 40001).

6
Return & Notify

Return MemoryRecord JSON. Notify MCP resources (bastion://stats). Auto-capture hooks persist tool call as memory.

The Search Pipeline — memory_search()
1
Embed Query

Query text → 1024-dim vector via same 3-tier embedding pipeline. Stopwords removed for keyword extraction.

2
C-SPANN ANN

ORDER BY embedding <-> query::vector LIMIT k. Distributed approximate nearest-neighbor via CockroachDB vector index.

3
Keyword Boost

BM25-like signal: count query keywords present in content. Weight: 2.0 × (hits / total terms). Fills gaps vector search misses.

4
Cognitive Decay

score = cos_sim × importance / (1 + 0.01 × age_hours). Fresher, more-accessed memories rank higher. Pinned memories survive.

5
Re-rank & Filter

Python-side hybrid re-ranking: 40% vector + 30% keyword + 15% entity + 15% temporal. Threshold filter (default 0.8).

6
Return Results

Ranked MemoryRecord list with individual signal scores. Cursor-based pagination for large sets.

The Self-Healing Loop — memory_heal()
1
Prune Expired

Delete memories where expires_at < now(). Native TTL handles most; this catches stragglers.

2
Walk Hash Chain

Iterate all memories for agent ordered by created_at. Recompute HMAC(content, meta, prev_hash) at each link.

3
Detect Tampering

If recomputed hash ≠ stored hash: prune the row. Never bless tampered data. Original hash preserved in audit trail.

4
Reseal Links

After pruned rows, recompute previous_hash for remaining valid memories. Chain integrity restored.

5
Audit & Report

Log all actions to agent_audit. Return healed state with tampered count, pruned count, and forensic details.
